# Amber Volley

Full-colour Python 3 neon gravity-volley arcade for [ElbowOS](https://x.com/ElbowOS).

Smash an amber orb over a gold net. Copper paddle at the baseline, teal rival at the far court. Gravity pulls the rally down. A / D or arrows slide. R reset.

## Play

```
pip install -r requirements.txt
python3 amber_volley.py --play
```

## Record a 9:16 reel

```
python3 amber_volley.py --record
```
